# FoodExpress Agile Plan

## Product
FoodExpress - End-to-End DevOps Application

## Sprint Goal
Integrate application development, Git-based version control, CI/CD automation, Docker deployment, ML lifecycle management, and application monitoring.

## Product Backlog

|---|---|---|---|

## Sprint Workflow

Planning
→ Development
→ Git Commit
→ CI/CD
→ Docker Build
→ Deployment
→ MLflow
→ Prometheus
→ Grafana
→ Review

## Definition of Done

A task is considered complete when:

- Source code is committed to Git.
- Required automated checks pass.
- Application can be deployed successfully.
- Docker container runs successfully.
- Required MLflow tracking is completed.
- Monitoring metrics are available in Prometheus.
- Monitoring dashboard is available in Grafana.
- Execution evidence is captured for the assignment.
